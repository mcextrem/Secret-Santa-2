# 🎄 Adventskalender-Wichteln

Ein einfaches, sicheres und vollständig lokales Tool zur Verteilung von Adventskalendern.

## Features
- **Keine Selbst-Zuordnung:** Garantiert durch den Sattolo-Derangement-Algorithmus.
- **Clientseitige Verschlüsselung:** Nutzt AES-GCM (Web Crypto API). Keinerlei Server-Backends erforderlich.
- **Deutschsprachige Benutzeroberfläche:** Für Admins und Teilnehmer.

## Installation auf GitHub Pages
1. Repository auf GitHub hochladen/pushen.
2. Auf GitHub im Repository zu **Settings** > **Pages** navigieren.
3. Als Quelle (`Source`) den Branch `main` / `master` und den Ordner `/ (root)` auswählen.
4. Speichern. Die Anwendung ist unter `https://<dein-username>.github.io/<repo-name>/` erreichbar.
